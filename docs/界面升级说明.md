# 高中英语学习界面升级

本轮针对高中生学习场景调整视觉和任务入口，沿用原有云函数、身份与评分规则。

## 已实现

- 暖白背景、深绿学习主卡片、纸质单词本装饰、统一卡片与按钮样式。
- 首页显示待完成、学习中、错词复习三个分栏；直接继续记忆、进入正式默写或开始错词练习。
- 记忆进度、截止时间、24 小时内截止和已逾期提示。
- 小组任务列表支持标题搜索、进行中、草稿、已撤回筛选。Member 不显示草稿筛选入口。
- 成绩页支持只看错词和查看全部，显示本地格式的提交时间。
- 词卡、默写、成绩、成员监督、排行榜、个人资料视觉统一。
- 首页请求部分失败时保留已成功获取的小组和任务；不将加载失败伪装成零任务。
- 学习建议卡片提供主动回想、语境辨义、默写与错词复习提示。

## 未改变的规则

允许逾期提交且正常评分；首次正式成绩不可覆盖；错词练习不修改成绩；Owner 不参与本组学习统计；权限和评分由服务端校验；批量录入仍采用粘贴文本。

## 查看和验收

在微信开发者工具打开现有项目并点击“编译”。首页配色、主卡片、操作入口和学习建议不依赖云数据库；真实任务、进度和错词需要已接入的云环境。

任务搜索和统计基于接口当前已加载的任务。现有任务接口每组最多返回 20 条，本轮没有改变这一接口；完整分页仍需后续联调补齐。
